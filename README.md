# 🛒 Web Simple Store 2

**Web Simple Store 2** adalah template website toko online sederhana berbasis HTML, CSS, dan JavaScript.  
Dirancang untuk memberikan struktur dasar toko digital yang mudah dikustomisasi dan ringan untuk dijalankan.  
Cocok digunakan sebagai:

- 💻 Toko pribadi atau usaha kecil
- 🧪 Proyek latihan front-end
- 🚀 Pondasi awal sebelum dihubungkan ke backend atau payment gateway

---

## ✨ Fitur

- 🖼️ Tampilan produk grid layout
- 🔍 Detail produk sederhana
- 🧾 Keranjang (basic UI - non-fungsional)
- 📱 Responsif untuk mobile dan desktop
- 🎨 Desain bersih dan mudah diubah

---

## 🚀 Cara Menggunakan

1. Clone atau download repository ini.
2. Buka `index.html` di browser kamu.
3. Untuk edit isi produk atau tampilan, modifikasi langsung di file HTML/CSS.
4. Hosting? Bisa langsung diunggah ke:
   - GitHub Pages
   - Netlify
   - Vercel
   - atau hosting statis lainnya

---

## 📁 Struktur Folder

📁 Web-Simple-Store-2 ├── 📄 index.html <- Halaman utama toko ├── 📁 css/ │ └── style.css <- File styling ├── 📁 js/ │ └── script.js <- (Optional) interaksi dasar ├── 📁 img/ │ └── product images <- Gambar-gambar produk


---

## 💡 Catatan

- Proyek ini **tidak terhubung ke database atau sistem pembayaran**, fokus utama adalah tampilan dan layout.
- Kamu bisa menambahkan fitur seperti cart, checkout, atau backend menggunakan PHP, Node.js, atau Firebase.
